# PRODIGY_WD_01 - Responsive Landing Page

A modern, responsive landing page built with HTML5, CSS3, and JavaScript. This project showcases web design best practices with a clean, user-friendly interface optimized for all device sizes.

## 📋 Overview

This responsive landing page demonstrates front-end development skills with a focus on:
- **Responsive Design** - Mobile-first approach that works seamlessly across all devices
- **Modern UI/UX** - Clean and intuitive user interface
- **Performance** - Lightweight and fast-loading pages
- **Accessibility** - Best practices for web accessibility

## ✨ Features

- **Fully Responsive Design** - Adapts perfectly to desktop, tablet, and mobile screens
- **Cross-browser Compatible** - Works smoothly across all modern browsers
- **Interactive Elements** - JavaScript-powered interactions and smooth animations
- **Clean Code** - Well-organized and maintainable code structure
- **SEO Optimized** - Proper HTML semantic structure for better search engine visibility

## 🛠️ Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Modern styling, flexbox, and grid layouts
- **JavaScript** - Interactive functionality and dynamic features

## 🚀 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/aceoroal/PRODIGY_WD_01.git
   cd PRODIGY_WD_01
   ```

2. **Open in your browser:**
   - Simply open the `index.html` file in your preferred web browser
   - Or use a local server (recommended):
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Python 2
     python -m SimpleHTTPServer 8000
     ```

## 💻 Usage

1. Open the landing page in your web browser
2. Explore the responsive design by resizing your browser window
3. Test on various devices (mobile, tablet, desktop)
4. Interact with the JavaScript-powered elements
